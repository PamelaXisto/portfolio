# 👩‍💻 Pâmela Xisto | Portfólio

Este é o repositório do meu portfólio pessoal, construído para apresentar meus projetos, habilidades e trajetória como Desenvolvedora Full Stack.

🔗 **Acesse o portfólio online:** [https://pamelaxisto.github.io/portfolio/](https://pamelaxisto.github.io/portfolio/)

## 🚀 Sobre o Projeto

O portfólio foi desenvolvido com um design moderno, minimalista e totalmente responsivo. Ele reflete minha identidade visual e organiza meus principais projetos desenvolvidos nas áreas de Front-end e Back-end (com foco em Java e React).

### 🛠️ Tecnologias Utilizadas no Portfólio
- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização com Flexbox, animações suaves, efeito glassmorphism e design responsivo (Mobile First).
- **JavaScript:** Interatividade da página, como a abertura das abas de detalhes dos projetos.

## 💻 Minhas Especialidades

Atuo no desenvolvimento de soluções completas, unindo lógica de negócio e interfaces funcionais:

- **Back-end:** Java, Spring Boot, Spring Data JPA, APIs RESTful, Maven/Gradle.
- **Front-end:** React, JavaScript, HTML5, CSS3.
- **Banco de Dados:** Modelagem e gestão em MySQL e PostgreSQL.
- **Infraestrutura/Outros:** Docker, Git, Arquitetura de Software e boas práticas (Clean Code).

## 🗂️ Como rodar o projeto localmente

Se desejar visualizar este projeto localmente na sua máquina:

1. Faça o clone do repositório:
   ```bash
   git clone https://github.com/PamelaXisto/portfolio.git
   ```
2. Abra a pasta do projeto no seu editor de código favorito (ex: VS Code).
3. Abra o arquivo `index.html` no seu navegador ou utilize a extensão *Live Server* do VS Code.
